## ✨ أبرز المميزات الهندسية والتربوية

1. **محرك الحصة والتسميع الخماسي (5-Axis Recitation Engine):**
   - إدارة التسميع الفعلي، الحفظ الجديد، المراجعة القريبة، المراجعة البعيدة، ومراجعة الأجزاء والأحزاب والسور.
   - **تسجيل المقاطع الصوتية بالميكروفون:** تسجيل مقاطع قصيرة لكل محور تسميع وتخزينها في حالة الطالب (`student.recitationAudioClips`) وقاعدة `IndexedDB` للرجوع إليها في أي وقت.
   - **وضع التركيز الخماسي (`Focus Mode`):** زر تبديل مباشر لإخفاء القوائم الجانبية وتوسيع مساحة السبورة الذكية لتقليل المشتتات أثناء التسميع.
   - **زر إرسال فويس قارئ / صوت المحفظ للنص الجديد:** إرسال الفويس الصوتي للنص الجديد بـ «صوت المحفظ» (مع زر تسجيل فوري مجاور) أو بأصوات المشايخ القراء (الحصري، المنشاوي، العفاسي، المعيقلي) مع نص الآيات المكتوب والمراجعات لولي الأمر عبر واتساب بضغطة واحدة.
2. **أداة تحليل التلاوة بالذكاء الاصطناعي (Gemini Audio Tajweed & Lahn Jali Analyzer):**
   - تحليل المقطع الصوتي المسجل عبر واجهة برمجة تطبيقات **Gemini (`@google/genai`)** لتقديم تقييم تلقائي لأحكام التجويد واللحن الجلي.
   - رصد أخطاء الحفظ والحركات الإعرابية (اللحن الجلي) وأحكام الغنن والمدود والمخارج (أحكام التجويد) مع إمكانية إدراجها بضغطة واحدة في سجل أخطاء الحصة وملاحظات ولي الأمر.
   - يدعم العمل عبر خادم Express (`POST /api/gemini/analyze-recitation`) مع محرك تحليل صوتي بديل (`Web Audio API DSP`) يعمل تلقائياً عند الاستضافة الساكنة على **GitHub Pages**.
3. **تبسيط بوابة ولي الأمر والأم والطالب (Simplified Easy Mode):**
   - واجهة مبسّطة افتراضية في شاشة واحدة بأزرار كبيرة وواضحة تتيح للأمهات وأولياء الأمور والطلاب ذوي الخبرة التقنية المحدودة متابعة ملخص التسميع، قراءة آيات الحفظ الجديد بالرسم العثماني، معرفة المراجعات المطلوبة، وسماع أو مشاركة فويس القارئ أو المحفظ بضغطة زر.
4. **النسخ الاحتياطي المشفر لقاعدة البيانات (`AES-256-GCM Encrypted JSON Backup`):**
   - تصدير قاعدة بيانات الطلاب والحلقات والحصص كملف JSON مشفر بكلمة مرور (`PBKDF2-SHA256` + `AES-256-GCM`) مع استيراد وفك تشفير البيانات تلقائياً عند إعادة التثبيت.
5. **السبورة القرآنية الذكية (3-Panel Interactive Smart Board):**
   - استوديو تفاعلي متعدد الصفحات يدعم الرسم الحر، الأشكال الهندسية، استيراد آيات المصحف العثماني، المسطرة الليزرية، المؤثرات الصوتية التفاعلية، ونظام جزيئات الاحتفال (`Particle Systems`: نجوم، بالونات، قصاصات).
6. **بوابات متعددة الصلاحيات (Multi-Portal RBAC):**
   - لوحة المالك والمشرف العام، بوابة المحفظ، بوابة الطالب، بوابة ولي الأمر، وبوابة المصحف العام والوقف والصدقة الجارية.

## 🚀 التشغيل المحلي والرفع على GitHub

### 1. التثبيت والتشغيل المحلي
```bash
npm install
npm run dev
```
- يعمل التطبيق محلياً على الرابط: `http://localhost:3000`
- لتفعيل تحليل Gemini السحابي على الخادم، انسخ ملف `.env.example` إلى `.env` وأضف مفتاح `GEMINI_API_KEY`.

### 2. البناء للإنتاج (Production Build)
```bash
npm run build
```

### 3. النشر التلقائي على GitHub Pages
المشروع مزوّد بملف سير عمل جاهز في `.github/workflows/deploy.yml`:
1. ارفع المشروع إلى مستودعك على GitHub (فرع `main` أو `master`).
2. من إعدادات المستودع على GitHub انتقل إلى **Settings → Pages**.
3. تحت قسم **Build and deployment (Source)** اختر **GitHub Actions**.
4. سيقوم GitHub Actions تلقائياً ببناء المشروع (`npm run build`) ونشر مجلد `dist` مع دعم تحديث الصفحات (`404.html`) والنطاق المخصص (`CNAME`).
